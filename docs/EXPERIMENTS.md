# Журнал опытов

Запись заводим до запуска: гипотеза и ожидание с числами. После запуска дописываем результат, путь к файлам оценок и вывод. Ожидание задним числом не правим.

Формат записи:

```
## <дата>. <опыт>
- Гипотеза:
- Ожидание:
- Запуск: модель, чекпойнт, наборы, вариант тишины, коммит
- Результат:
- Вывод:
```
