# 6. Метрики и вычислительная стоимость

- EER и EER по каждой атаке. min t-DCF требует оценок ASV, они есть только для ASVspoof 2019/2021 LA. a-DCF — метрика трека SASV в [ASVspoof 5](https://arxiv.org/abs/2408.08739), для одиночного детектора не подходит; для него там основная minDCF, плюс actDCF и Cllr. Ошибка при пороге, зафиксированном на dev (HTER), и калибровка разобраны в теме 3.
- Стоимость дообучения XLS-R 300M, хватит ли GPU, нужны ли заморозка слоёв или LoRA. Ложится во второй критерий оценки. Попутно найдено: нижних слоёв XLS-R хватает (El Kheir 2025), замороженный XLS-R с логистической регрессией почти бесплатен (Pascu 2024). Искать LoRA и адаптеры для anti-spoofing за 2024–2026.
