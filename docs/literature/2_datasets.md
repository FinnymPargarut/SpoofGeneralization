# 2. Датасеты и подводные камни

- **ASVspoof 2019 LA**: атаки A07–A19 только в eval; A16 и A19 используют те же алгоритмы, что A04 и A06 (проверено по статье о базе).
- **ASVspoof 2021 LA/DF** (кодеки, телефонный канал) и **ASVspoof 5** (2024, краудсорсинг, около 2000 дикторов, 32 алгоритма атак). В DF 2021 часть живой речи из VCC, на ней детекторы ошибаются в разы чаще (тема 1а).
- **Наборы «из реальной жизни»**: In-the-Wild (Müller 2022), WaveFake, MLAAD, CodecFake. Под именем CodecFake два разных набора: [Wu et al.](https://arxiv.org/abs/2406.07237) и [Xie et al.](https://arxiv.org/abs/2405.04880), есть ещё [CodecFake+](https://arxiv.org/abs/2501.08238). Искать наборы 2025–2026: многоязычные, из соцсетей, с новыми TTS, с перезаписью. Попутно уже попались: Deepfake-Eval-2024, [ML-ITW](https://arxiv.org/abs/2603.05852), VoxENES 2026, ReplayDF, SpoofCeleb, SpeechFake.
- **Ловушки в данных**: в ASVspoof 2019 длина тишины в начале записи сама по себе неплохо отделяет подделку от живой речи (Müller 2021, «Speech is Silver, Silence is Golden»). Без проверки таких эффектов можно измерить не то. Тишина лишь одна из ловушек: для каждого набора пройти чек-лист из 1а (длительность и содержимое тишины, источник и канал живой речи, кодек и формат, громкость, частота дискретизации, тексты, пол дикторов, водяные знаки).
- **На чём учить**: в ML-ITW одна и та же XLS-R + AASIST даёт на In-the-Wild от 2,6% до 48% EER только от выбора обучающего набора. Выбор обучающих данных влияет сильнее архитектуры, его надо обосновать отдельно.

Источники ниже сверены по полным текстам и коду (13.10.2026). Формат строки: кто и где, что нашли, вывод для нас.

## Как резали тишину

- **Müller et al. 2021**, ASVspoof 2021 Workshop (тема 1а). librosa.effects.trim с порогом 40 дБ ниже максимума записи (top_db=40), остальные параметры не указаны (в librosa по умолчанию кадр 2048 и шаг 512 отсчётов). Режут только начало и конец. Классификатор тишины: сеть с двумя скрытыми слоями по 128 на одном признаке, длине начальной тишины по тому же trim; EER на dev 31,09%, на eval 15,12% (среднее четырёх запусков). На eval лучше, потому что там больше TTS-атак без тишины (A07–A16). Обрезка и в обучении, и в тесте (раздел 4.3): RawNet2 с 3,61% до 15,50% на 2019 eval. Обрезка только в тесте у модели, обученной с тишиной: LSTM с 7,35% до 35,32%. [arXiv:2106.12914](https://arxiv.org/abs/2106.12914)
- **Liu et al. 2023**, IEEE/ACM TASLP (итоги ASVspoof 2021, тема 1а). Скрытые подмножества LA и DF сделаны энергетическим VAD с рекомендованными порогами из Kinnunen, Li 2010 (раздел 5.1). Удалена вся неречь, и по краям, и между словами; паузы короче 50 мс считаются речью, куски речи короче 50 мс выбрасываются. LA hidden из всех условий C1–C7, DF hidden из всех условий, но только с исходником ASVspoof 2019 LA. В рейтинге не участвовали. У топ-10 EER на основном eval меньше 10%, на скрытом больше 20%. Опыт с бейзлайнами в приложении (табл. X), RawNet2 (B04) на LA: с тишиной 9,50%, без пауз между словами 7,80%, без тишины по краям 35,00%, без всей неречи 37,97%; на DF 6,22%, 4,85%, 32,32%, 34,65%. [arXiv:2210.02437](https://arxiv.org/abs/2210.02437)
- **Ключи ASVspoof 2021.** Скрытые записи уже лежат в eval LA и DF и отмечены в ключах (метка trim, подмножество hidden), резать самим не надо. [eval-package](https://github.com/asvspoof-challenge/2021/tree/main/eval-package)
- **Скрипт NII** (Xin Wang, один из организаторов ASVspoof), функция silence_handler со ссылкой на тот же раздел Kinnunen, Li. Кадр 320 отсчётов (20 мс), шаг 80 (5 мс); энергия кадра в дБ по стандартному отклонению отсчётов; кадр речевой, если энергия выше максимума записи минус 30 дБ и выше −55 дБ; затем паузы и куски речи короче 50 мс сглаживаются. Совпадает с описанием 2021 года, но что скрытые подмножества сделаны именно этим кодом, прямо не сказано. [wav_tools.py](https://github.com/nii-yamagishilab/project-NN-Pytorch-scripts/blob/master/core_scripts/data_io/wav_tools.py)
- **Wang, Yamagishi 2023**, ICASSP (тема 4). LA19etrim: 2019 LA eval, обрезанный этим VAD только по краям с запасом 5 кадров (25 мс). Выложены не аудио, а номера отсчётов начала и конца речи для train, dev и eval, и скрипт обрезки. [Zenodo 7314976](https://zenodo.org/records/7314976), файл project09-ASVspoof2019LA-etrim.tar

Итог. Для повтора классификатора тишины Müller нужен librosa trim с порогом 40 дБ. Для eval без тишины удобнее LA19etrim: инструмент описан, отметки готовы, есть цифры для сверки, а отметки для train и dev пригодятся на этапе 4. Скрытые подмножества 2021 — второй вариант, но там вырезаны и паузы между словами, и есть кодеки. По опыту 2021 ярлык сидит в тишине по краям: паузы между словами на EER почти не влияют.

## Подводные камни In-the-Wild

- **Müller et al. 2022**, Interspeech (тема 1а). 58 англоязычных знаменитостей и политиков, 37,9 ч, средняя длина клипа 4,3 с, всё в wav и 16 кГц. Подделки нарезаны из 219 открытых видео и аудио, которые сами объявлены дипфейками; живая речь собрана вручную из подкастов, выступлений и т. п., с попыткой подобрать похожие стиль, эмоции, фон и длительность. Задуман только как тестовый набор, разбиения нет. По Zhou, Wang 2026: 31 779 записей, из них 19 963 живых (62,8%) и 11 816 подделок. [arXiv:2203.16263](https://arxiv.org/abs/2203.16263)

Камни:
1. Классы из разных источников: подделки из роликов авторов дипфейков, живая речь из подкастов и выступлений. Ручной подбор фона не гарантирует одинаковых записи и постобработки, модель может ловить их, а не синтез. Проверки таких ярлыков на In-the-Wild не нашли; до выводов прогнать на нём наш чек-лист (тишина по краям, громкость, спектр).
2. Подделки нарезаны из 219 исходников: клипы одного ролика похожи, независимых примеров намного меньше 11 816, и интервалы по клипам выйдут слишком узкими (вывод наш, в литературе не нашли).
3. Меток генератора нет, EER по атакам не посчитать.
4. 63% живых и сдвиг рабочей точки: при EER 7–11% точность 56% (ML-ITW), а при пороге из ASVspoof отвергнуто 78,7% живых (Zhou, Wang). Точность не публиковать, только EER, HTER, FRR и FAR.
5. Только для теста. Если брать для обучения или выбора модели, делить по дикторам: у каждого диктора есть оба класса. Работы, которые выбирают модель по In-the-Wild (Dao IDFE, тема 4), дают уже не внешние цифры.
6. Длина входа. Средний клип 4,3 с, код Tak смотрит только первые 4 с; у Müller 2022 вход, обрезанный до 4 с, хуже полной записи на In-the-Wild. Обработку длины держать одинаковой для всех моделей.
7. Формат. На Hugging Face один архив release_in_the_wild.zip (8,16 ГБ) и единственный сплит train, хотя это весь тест. Разметка в meta.csv: колонки file, speaker, label, метки bona-fide и spoof (с дефисом, в ASVspoof bonafide); колонки взяты из стороннего загрузчика, проверить после скачивания. [Hugging Face](https://huggingface.co/datasets/mueller91/In-The-Wild)
8. Сильные современные модели дают на In-the-Wild 1–3% (тема 4), для них разрыв он уже не показывает. Для наших моделей, обученных только на ASVspoof 2019, он остаётся внешним тестом.
